## ЧТО ПОСТРОИТЬ

**«Маркетинг»** — внутренний дашборд, который сводит весь анализ в одну навигируемую панель для владельца/команды. (Это раздел сайта; по смыслу — дашборд из 9 модулей анализа, который раньше обсуждался как «командный пункт».)

### Интеграция с сайтом (обязательно)
- **Главная страница остаётся сайтом, который уже сделан, без изменений.** Не трогай её контент и структуру.
- Единственное добавление на главной — **один пункт «Маркетинг» в хедере**. Слайд в слайдере НЕ добавлять.
- По клику на «Маркетинг» открывается раздел-дашборд (роут вида `/marketing`).
- **Навигация назад:** внутри дашборда, при переходе в любой модуль, вверху всегда видны две кнопки:
  - `← Вернуться на главную` (= на главную сайта),
  - `← В Маркетинг` (к обзорному экрану дашборда).
- Сохрани шапку и подвал существующего сайта. Дашборд должен выглядеть как родная часть сайта, а не отдельная вставка.

### Технические требования
- Встраивай в **тот же стек, на котором сделан сайт** — сначала определи его (Next.js / статический HTML / другое) и используй его же компоненты и роутинг. Не тащи новый фреймворк.
- Используй существующую **дизайн-систему**: тёмный фон `#0D0D1A`, карточки `#1A1A2E`, золото `#D4A017` (акцент), женское направление `#C2185B`, шрифт Inter, карточки со скруглением 16px, мягкие тени. Если в проекте уже есть токены/переменные — переиспользуй их.
- Графики — через ту библиотеку, что уже есть в проекте; если её нет, подключи лёгкую (Chart.js или подобную) через существующий механизм сборки.
- Адаптивность: корректно на десктопе и мобильном.
- Не использовать localStorage/sessionStorage.

### МОДУЛЬ 1. ФИЛОСОФИЯ И СМЫСЛЫ
Источник: анализ книг, блоки 1, 2, 8.
- **Карта философии** — интерактивный граф связей ключевых концепций: «Жизнь без трусов» (центр) → «Отношения = игра» → «Игроки (4 уровня)» → «Мастер / Охотница» → инструменты (раскачка эмоций, якорение, игра на понижение) → результат (влюблённость → отношения → замужество). Боковая панель: фундаментальные идеи, что менялось по книгам, ключевой инсайт («продаётся не техника, а разрешение»).
- **Словарь терминов** — таблица с поиском: термин, определение по Лесли, эмоциональный заряд (★), маркетинговый потенциал. Топ-термины вынести отдельно (Охотница, Жизнь без трусов, 21 день, Та, которую выберут, Турбоядерные техники).
- **Психологический профиль бренда** — почему идут к Лесли (permission marketing и др.), две колонки «вызывает доверие / вызывает сопротивление», две колонки «нельзя менять / можно модернизировать», архетип бренда.

### МОДУЛЬ 2. АУДИТОРИЯ
Источник: анализ книг блок 3 + стратегия блоки 3, 5.
- **Карта болей** — 14 категорий болей карточками; у каждой шкалы «глубина (1–5)», «мотивация платить (1–5)» и «лучший продукт». Сводная диаграмма: ранжирование болей по мотивации платить. Выделить топ-3 (не зовёт замуж / 35+ / он пропал).
- **20 сегментов ЦА** — фильтруемая таблица или карточки: сегмент, возраст, доход, главная боль, страх, желание, возражение, триггер покупки, путь клиента, канал. Пометить топ-3 приоритетных сегмента.
- **Спрос и сезонность** — таблица поисковых запросов (Wordstat): запрос, частота/мес, тренд, коммерциализация (★). Отдельно — точки роста (замуж после 35/40, замуж за состоятельного, онлайн-знакомства, ИИ-коуч) и календарь сезонности спроса по месяцам.

### МОДУЛЬ 3. ЖЕНСКОЕ НАПРАВЛЕНИЕ
Источник: анализ книг блоки 4, 5.
- **Модель «Охотницы»** — 9 шагов как горизонтальный/вертикальный путь (Разрешение → Выбор объекта → Первый контакт → Прогрев → Якорение → Турбоядерные техники → Переход к отношениям → Удержание → Замужество).
- **Что актуально в 2026** — таблица: элемент, статус в 2026, что обновить (тег «актуально» / «требует обновления» / «основа продукта»).
- **6 сценариев** для нового продукта (первый контакт онлайн, первое свидание, он пропал, перевод в отношения, предложение руки, привлечь успешного) — карточки.
- **Каталог техник (20)** — фильтруемый список: техника, источник (книга), суть, применение, тег уровня продукта (лидмагнит / трипваер / основной / клуб / VIP). Сводка «распределение техник по уровням продукта».

### МОДУЛЬ 4. ПРОДУКТЫ И ВОРОНКИ
Источник: анализ книг блок 6 + стратегия блоки 13, 14, 15.
- **Продуктовая матрица / линейка** — визуальная воронка снизу вверх: бесплатно → трипваеры → основной курс → подписка/клуб → VIP → офлайн. Каждый уровень кликабелен: название, формат, цена, УТП, основа из книг.
- **Закрытый клуб «Академия Охотниц»** — 4 тарифа (СТАРТ / БАЗА / ПРОДВИНУТЫЙ / ELITE): цена, что входит, лимит, целевой LTV, churn. Блок геймификации и удержания.
- **Воронки** — 20 лидмагнитов и 20 трипваеров (таблицы с конверсиями и апселлом) + 5 схем воронок (короткая, вебинарная, клубная, SEO, запуск) с их KPI.

### МОДУЛЬ 5. КОНТЕНТНАЯ МАШИНА
Источник: анализ книг блок 7 + стратегия блоки 6, 7, 8.
- **Библиотека идей (1800+)** — фильтр по типу: Reels (500), Shorts (500), Telegram-посты (500), прямые эфиры (200), вебинары (100). Поиск по тексту. Для каждой категории/идеи — три бейджа-оценки: вовлечение (В), виральность (Вир), продажи (Пр). Сверху сводка по объёму каждого типа.
- **Контент-планы по каналам** — таблицы частоты/форматов из стратегии (Telegram принцип 365 дней, Instagram форматы, YouTube архитектура).

### МОДУЛЬ 6. КАНАЛЫ И РОСТ
Источник: стратегия блоки 6, 7, 8, 9, 16.
- **Telegram** — архитектура экосистемы (канал, клуб, чат, бот, VIP), схема автоворонки (7 шагов), KPI по месяцам (диаграмма).
- **Instagram** — форматы/частота, KPI по месяцам.
- **YouTube** — архитектура контента, KPI по месяцам (до 18 мес).
- **Сбор аудитории** — таблица «где находится ЦА / как находить / как привлекать / конверсия» по платформам.
- **Growth hacking** — 100 способов роста по 6 категориям (вирусный контент, комьюнити, коллаборации, SEO, ценообразование, PR, технологии) — фильтруемый список.

### МОДУЛЬ 7. РЫНОК И КОНКУРЕНТЫ
Источник: стратегия блоки 2, 4.
- **Анализ рынка** — таблица объёмов сегментов с прогнозами 2027/2030, демографические драйверы (браки/разводы/одинокие женщины и т.д.), тренды 2024–2026.
- **100 конкурентов** — фильтруемая таблица по 8 категориям (медийные психологи, спец-коучи «как выйти замуж», брачные агентства, женские клубы, дейтинг-приложения, инфобизнес-эксперты, международные аналоги, YouTube/TG-каналы): имя, платформа, аудитория, оффер, цены, отличие. Отдельно — сравнение топ-5 прямых конкурентов (радар/таблица по параметрам).

### МОДУЛЬ 8. ТЕХНОЛОГИИ И АВТОМАТИЗАЦИЯ
Источник: стратегия блоки 10, 11, 12.
- **Парсинг и автоматизация** — таблица «задача / инструмент / что даёт» + система скоринга лидов (признаки и баллы, правила приоритизации).
- **SEO** — семантическое ядро кластерами (кластер, примеры запросов, объём, тип страницы, коммерция) + типы страниц для создания + SEO-прогноз.
- **Мобильное приложение** — концепция «Охотница: путь к замужеству», функции MVP с приоритетами, финансовая модель приложения (сценарии MAU/выручка). Указать вердикт «делать, но не сейчас».

### МОДУЛЬ 9. ФИНАНСЫ И ПЛАН
Источник: стратегия блоки 1, 17, 18.
- **Аудит экосистемы** — профиль медийной личности, карта текущих каналов и продуктов, текущий клиентский путь, ключевые проблемы и возможности.
- **Финансовая модель** — метрики воронки (CPL, конверсии, CAC, LTV, маржа, churn), сценарная модель по объёму лидов (1k / 5k / 10k / 50k лидов/мес) с выручкой и оценкой бизнеса. Путь к оценке 1 млрд ₽ по этапам/месяцам (диаграмма).
- **Дорожная карта** — таймлайн запуска: дни 1–10, 11–20, 21–30, месяц 2, месяцы 2–6. Без перехода в горизонт «5 лет».
